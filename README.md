# 🧠 Project-Soul: The Persistent AI Agent Framework

> **"Because your AI shouldn't have Alzheimer's."**

Project-Soul is a lightweight, folder-bound framework to give your AI agents (like Gemini CLI, Claude, or Cursor) a persistent **Personality** and **Memory** that follows your project folder. No cloud needed. Totally local. Fully portable.

## 🌟 Why Project-Soul?

*   **Folder-Bound Context**: Each project has its own "Brain" and "Soul".
*   **Persistent Memory**: Never repeat yourself. The AI remembers your API keys, build steps, and that one weird bug from last week.
*   **Portable Soul**: Moving to a new PC? Just copy the `.md` files. Your AI wakes up with the same attitude.
*   **Privacy-First**: No data sent to proprietary "memory" clouds. Your secrets stay in your Markdown.

## 🛠️ How it Works

1.  **GEMINI_SOUL.md**: Defines the agent's identity, language style, and core instructions.
2.  **GEMINI_MEMORY.md**: A structured ledger where the agent records achievements and project status.
3.  **The Hook**: A small configuration in your global agent settings that tells it to "Wake Up" when a keyword is typed.

## 🚀 Quick Start

1.  Clone this repo.
2.  Run `python setup_soul.py` in your target project folder.
3.  Type `gemini_rocks` (or your chosen keyword) to wake up the Soul.
